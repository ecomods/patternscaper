# Reject multi-layer landscapes in the pixel workflow

Reject multi-layer landscapes in the pixel workflow

## Usage

``` r
abort_on_multilayer_landscapes(landscapes, action)
```

## Arguments

- landscapes:

  List of landscape objects.

- action:

  Character. Verb naming what the caller was about to do, used in the
  error message.

## Value

Invisibly \`NULL\`. Called for the error.
