# Create a new landscape object

Internal constructor for landscape objects.

## Usage

``` r
new_landscape(
  data,
  pattern = NA_character_,
  name = NA_character_,
  params = NULL
)
```

## Arguments

- data:

  SpatRaster containing landscape data

- pattern:

  Character string specifying landscape pattern

- name:

  Character string specifying landscape name

- params:

  List of parameters used to create the landscape

## Value

A landscape object
